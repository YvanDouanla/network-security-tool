## Question 1 : Quelle est la différence entre git add et git commit ?

git add place les modifications sélectionnées dans la zone de préparation (index). git commit enregistre le contenu préparé dans l'historique du dépôt local.

## Question 2 : Que représente un commit dans Git ?

Un commit représente un instantané du projet enregistré dans l'historique. Il possède un identifiant, un auteur, une date, un message et une référence à son ou ses commits parents, sauf pour le premier commit.

## Question 3 : Pourquoi créer une branche plutôt que modifier directement la branche principale ?

Une branche permet de développer et de tester une fonctionnalité séparément, en préservant la version de la branche principale. Elle facilite le travail en parallèle et la revue des modifications avant leur fusion.

## Question 4 : Quel est le rôle d'une Pull Request dans un projet collaboratif ?

Une Pull Request propose de fusionner les modifications d'une branche dans une autre. Elle permet de comparer les changements, d'en discuter, de les faire relire et de vérifier les tests avant la fusion.
